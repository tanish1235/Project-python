#PROBLEM STATEMENT
students often spend money on food, travelling, stationery, shopping and other daily activities. However, they don't always keep track of their expenses.
This project helps students record their daily expenses and calculate how much money they spend.


#CONCLUSION
The Student Daily Expense Tracker is a beginner-friendly Python project that solves a common real-world problem. It helps students understand how Python programming can be used in everyday life. Through this project, we learn important concepts such as variables, lists, loops, conditional statements and functions.
